# HNSW Indexing & Partitioning Strategy

> **This document has been moved to the shared-libs-python library.**
>
> See: https://github.com/hseshadr/shared-libs-python
>
> The `shared-libs-python` library provides reusable implementations of:
> - `GlobalPartitionStrategy` - Single global HNSW with metadata filtering
> - `BucketedPartitionStrategy` - Hash-based tenant bucketing for 50K+ tenants
> - `TwoTierPartitionStrategy` - Hot/cold separation for large historical datasets
>
> For integration details in AML-Filter, see [VECTOR_LIBRARY.md](./VECTOR_LIBRARY.md).
